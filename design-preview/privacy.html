Stripe stripe.com · США/ЕС
Обработка платежей за Premium и Семейный планы. Применяется только при оформлении подписки — не на бесплатном плане.
Передаётся: email, имя на карте, номер карты (через Stripe Elements — Sakeenly не видит сам номер), сумма платежа.

Plausible self-hosted · Германия
Агрегированная аналитика: какие страницы открывают, какие переводы выбирают. Без cookies, без отпечатка устройства, без личной идентификации.
Передаётся: URL страницы, referrer, ОС-категория («Android / iOS / Windows»), агрегированная страна. Не передаётся: IP (анонимизируется на сервере).
Обязателен · все
Sentry self-hosted · Германия
Сбор ошибок JavaScript и серверных исключений, чтобы быстрее их чинить. PII и тексты заметок отсекаются на клиенте.
Передаётся: stack trace, URL, версия браузера, ID сессии (анонимный). Не передаётся: email, заметки, тексты вопросов в /ask.
Можно отключить
Anthropic API anthropic.com · США
LLM для ответов на вопросы в /ask. Вопросы отправляются Anthropic для генерации ответа, не сохраняются у них для обучения (опция zero-retention).
Передаётся: текст вопроса + извлечённые из Quran/Hadith цитаты. Не передаётся: email, имя, ID пользователя.
Только при /ask
Quran.com API quran.com · публичный
Получение текста аятов, переводов, аудио и тафсиров. Публичный read-only API. Не требует аутентификации.
Передаётся: только номер суры и аята. Не передаётся: идентификаторы пользователя.
Анонимный
Supabase supabase.com · ЕС-Frankfurt
Хост базы данных и аутентификации. На европейском регионе. Sakeenly — единственный, кто имеет доступ к данным.
Хранится: email, хеш пароля, закладки (шифрованы), заметки (шифрованы), streak, подписка.
Обязателен · авториз.
Vercel vercel.com · США/ЕС
Хостинг сайта (CDN + serverless функции). Передаёт логи запросов без данных аккаунта.
Логи: IP, URL, время ответа — хранятся 30 дней. Не хранится: тело запросов с PII.
Хостинг

Глава 3 · шифрование

Как заметка попадает в базу.

Цепочка из четырёх шагов, на каждом из которых данные не читаемы посторонним сервисом.

01 · Браузер Ты пишешь заметку Текст существует только в твоём браузере. Никуда не отправлен.
02 · TLS Передача по HTTPS TLS 1.3 (Vercel Edge). Между тобой и сервером — никто не читает.
03 · Сервер AES-256 шифрование Текст заметки шифруется ключом из envelope-encryption. Ключ хранится в Vercel KV, не в Supabase.
AES-256-GCM
Алгоритм
Стандарт NIST. Без поломанных режимов.
90 дн
Ротация ключей
Каждые 90 дней основной ключ перевыпускается. Старые сохраняются для дешифровки.
2-сервиса
Разделение
Данные — в Supabase. Ключи — в Vercel KV. Один сервис не видит другого.
30 дн
Удаление
При удалении аккаунта данные стираются за 30 дней. Бэкапы — за 90.
